<h1 align="center">KonoSite</h1>

<div align="center">

A personal homepage — Material You design, customizable, self-hosted.

Forked from [Material You NewTab](https://github.com/prem-k-r/MaterialYouNewTab) by [XengShi](https://github.com/XengShi) & [Prem](https://github.com/prem-k-r/).

</div>

## Features

- **Search** — Google, Bing, DuckDuckGo, YouTube, Wikipedia, Medium article search, and more
- **一言 quotes** — Hitokoto API integration with category and interval settings
- **Bookmarks** — localStorage-based bookmark manager with add/edit/delete
- **Projects** — Auto-fetches your GitHub repos
- **Weather** — Real-time weather with customizable location
- **Clock** — Analog or digital, 12/24h format
- **Themes** — Light, dark, black themes with Material You color picker
- **Wallpaper** — Upload custom or daily random from Lorem Picsum
- **Todo List** — Daily tasks with pin and auto-cleanup
- **AI Tools** — Quick links to ChatGPT, Gemini, Copilot, Claude, DeepSeek, and more
- **Shortcuts** — Customizable quick links with adaptive icons
- **Social Links** — Sidebar with personal and friend links

## Quick Start

```bash
git clone https://github.com/SakuraCake/MaterialYouNewTab.git
```

Open `index.html` directly, or serve with any static server:

```bash
# Python
python -m http.server 8080

# Nginx
# Point root to the cloned directory
```
